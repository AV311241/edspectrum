class_profile
Purpose

This doc stores the Lumino1 Classroom Profile and Planning Bridge for a selected class/section. It captures class-level assessment information and planning fields used to prepare for the next planning stage.

Fields
Field	Type / Instruction
School	Selected school
Class/Section	Selected class and section
Students assessed	Number of students assessed
Assessment date	Assessment date
Strong domains	Class domains showing stronger readiness
Weak domains	Class domains requiring more support
Cross-domain pattern	Manual; use 06_Cross_Domain_Guide after reading the domain pattern
Communication bottleneck	Manual; write the main language bottleneck blocking communication
Provisional language direction	Planning field
Possible central language function	Select from dropdown
Compatible theme	Select from dropdown
Immediate planning implication	Planning field
Ready for Table 39 row-bundle selection?	Readiness status for the next planning step
Default Readiness Status

When required school/class information and data have not been entered:

No - select school/class and enter data
